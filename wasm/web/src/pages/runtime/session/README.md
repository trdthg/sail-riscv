# `src/pages/runtime/session/`

Runtime debug session domain state.

- `runtimeSessionReducer.ts` — session state schema + reducer.
- `runtimeSessionContext.ts` — context contract for session state/actions.
- `runtimeSessionActions.ts` — typed action creators.
- `runtimeSessionSelectors.ts` — pure selectors for register rows/diff helpers.
- `RuntimeSessionProvider.tsx` — session context provider.
- `useRuntimeSession.ts` — runtime session state/actions/selectors hooks.
